# backend-agent-test 🚀

Simple Java CLI example that runs a binary search on integer inputs 🔎.

## Build 🛠️

From the repository root:

```bash
javac src/Main.java
```

## Run ▶️

Pass sorted array elements followed by the target value:

```bash
java -cp src Main 1 2 3 4 5 3
```

Example output 📌:

```text
Result index: 2
```
