# backend-agent-test

A simple Java project demonstrating a binary search implementation.

## Build

```bash
javac src/Main.java
```

## Run

```bash
java -cp src Main <array elements> <target value>
```

**Example:**

```bash
java -cp src Main 1 2 3 4 5 5
```

This searches for the value `5` in the sorted array `[1, 2, 3, 4, 5]` and prints the result index.
