# backend-agent-test

Simple Java CLI app with a binary search example.

## Requirements

- Java (JDK 8+)

## Compile

```bash
javac src/Main.java
```

## Run

```bash
java -cp src Main 1 2 3 4 5 5
```

## Usage

```bash
java Main <array elements> <target value>
```

Example:

```bash
java Main 1 2 3 4 5 5
```
