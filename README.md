# backend-agent-test

Simple Java CLI app with a binary search implementation.

## Requirements

- Java (JDK 8+)

## Build

From the repository root:

```bash
javac src/Main.java
```

## Run

Pass sorted array elements followed by the target value:

```bash
java -cp src Main 1 2 3 4 5 6
```

Example output:

```text
Result index: -1
```
